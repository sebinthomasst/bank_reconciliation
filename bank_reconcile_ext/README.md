# Bank Reconciliation Module

Reconcile bank statements with GL account entries.

## Description
This Odoo 14 module provides a professional financial reconciliation workspace. It allows accountants to verify, flag, and match bank statement balances with system GL logs, and to generate comprehensive Excel reconciliation reports.

## Features
* **Period Selection**: Match transactions for specific journals and date ranges.
* **Auto-Balance Calculation**: Instantly computes GL opening balance, period debit/credits, ending balance, and physical statement mismatch.
* **Batch Operations**: "Select All" and "Unselect All" options for quick matching.
* **Excel Reporting**: Export clean, standard Excel (.xlsx) reconciliation logs.
* **Standards Compliant**: Clean modular file structures conforming fully with Odoo code guidelines.

## Installation
1. Ensure the module dependency `report_xlsx` is installed in your Odoo environment.
2. Copy this directory (`bank_reconciliation`) to your Odoo custom addons directory.
3. Update the Apps List in Odoo and install **Bank Reconciliation**.
