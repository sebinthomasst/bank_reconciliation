Usage Instructions
==================
1. Navigate to Invoicing/Accounting -> Actions -> Journal Entries -> Bank Reconciliation.
2. Create a new Bank Reconciliation record.
3. Select the Bank Journal and GL Account.
4. Specify the period from-date and to-date.
5. Click "Reload" to pull all journal entries within the period.
6. Check the "Reconciled" box for each corresponding transaction.
7. Fill in the "BNK Balance" (statement closing balance).
8. Verify that the "Difference" becomes zero, then click "Validate".
